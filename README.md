# HMĐ Drone For Everyone

Static Vietnamese landing page for the HMĐ Drone For Everyone STEM project.

## Publish with GitHub Pages

The site is served from `index.html` at the repository root. In the repository settings, choose **Pages**, then deploy from the `main` branch and the `/ (root)` folder.

The original HTML referenced five photos that were not included with the supplied file. This project uses original local SVG illustrations in `assets/` so the public page has no broken image links. Replace them with the original photos whenever those files are available.

The cart and profile forms are demo interactions stored in the visitor's browser. Checkout is not connected to an order system.
